# Nexus Connect

Design and develop a completely original, premium multi-page Cable & Internet service website with a futuristic technology-inspired aesthetic that is distinctly different from conventional ISP websites and does not resemble the reference sites in layout, color palette, or visual hierarchy. The website should feel innovative, premium, and highly trustworthy while maintaining excellent readability and fast loading performance. Instead of the typical blue-and-white telecom appearance, use a sophisticated dark emerald (#0F3D3E), charcoal (#1A1C1E), soft ivory (#F7F6F2), warm gold (#D4AF37), and mint green (#63D8B4) color palette. The overall visual identity should combine modern technology with premium lifestyle branding, using soft glassmorphism, layered cards, subtle mesh gradients, elegant shadows, organic curved section dividers, abstract network patterns, and premium illustrations inspired by digital connectivity. Every section should have its own visual identity rather than repeating the same card layouts. Use large rounded containers, floating UI elements, modern iconography, premium typography, and high-quality real lifestyle photography of families, remote professionals, gamers, students, and businesses using internet services. Avoid AI-generated images and instead use authentic, realistic imagery. Keep animations elegant and lightweight with fade-ins, floating illustrations, number counters, smooth hover interactions, and gentle scrolling effects without creating a heavy or laggy experience.

Create a clean sticky navigation bar with a horizontal logo, navigation links for Home, Broadband, Internet, Cable TV, Coverage, Support, FAQ, and Contact, along with two premium CTA buttons labeled "Check Coverage" and "Get Started." Design a completely unique hero section that avoids the common split-screen layout. Instead, create a layered composition where the headline and call-to-action are placed inside a floating premium glass panel positioned over a large immersive background image showing a modern connected home with subtle digital network overlays. Surround the hero content with animated floating connectivity indicators, Wi-Fi waves, fiber light trails, and abstract technology graphics. Use the headline "Smarter Connectivity for Every Home & Business" with a supporting paragraph explaining that the platform helps users explore broadband and cable connectivity options available in their area while simplifying the entire connection request process. Do not mention being a third-party provider in the hero section or in the primary headline. Include two visually striking CTA buttons encouraging users to check coverage or connect with a specialist, followed by a premium trust bar highlighting Fast Assistance, Flexible Connection Options, Secure Process, and Dedicated Customer Support.

Replace the standard ZIP checker with a visually impressive "Coverage Finder" section designed as a floating search module featuring an interactive map-inspired background. Allow users to enter their ZIP code, city, or locality to instantly check service availability. Continue with a beautifully designed "Why People Choose Us" section using asymmetrical alternating layouts instead of traditional cards. Each feature should combine modern illustrations with descriptive content covering fast connection guidance, multiple network options, dedicated customer assistance, simple request handling, flexible broadband recommendations, and reliable support throughout the process. Follow this with an immersive "Designed for Every Lifestyle" section using large horizontal feature panels for Home Entertainment, Gaming & Streaming, Remote Work, Small Business, Smart Homes, and Online Learning, each accompanied by unique imagery and subtle animated backgrounds.

Create a visually engaging "Connection Journey" section using a modern curved timeline instead of a traditional horizontal process bar. Illustrate the customer journey through animated milestones including Check Coverage, Explore Options, Submit Request, Expert Assistance, and Get Connected. Design a premium "Connectivity Features" section using staggered floating content blocks highlighting Ultra-Fast Internet, Stable Connections, HD Streaming, Multi-Device Support, Work From Anywhere, Smart Home Integration, Secure Networking, and Responsive Customer Assistance. Instead of displaying internet plans with pricing, present a beautifully designed "Connection Categories" section featuring Explorer, Family, Professional, and Business solutions with elegant illustrations, descriptive content, and a "Learn More" or "Check Coverage" button for each category.

Develop an eye-catching Cable TV showcase featuring cinematic entertainment imagery displayed within overlapping curved containers rather than standard image-and-text columns. Explain how users can explore entertainment, sports, regional programming, kids' content, and premium television options available through supported providers in their location. Add a dedicated Smart Living section highlighting Wi-Fi optimization, mesh networking, home office connectivity, router setup, streaming optimization, and connected device assistance using interactive icons and modern isometric illustrations. Include an animated statistics section where elegant counters display metrics such as Successful Connection Requests, Areas Supported, Happy Customers, and Customer Satisfaction, each presented within premium floating information tiles.

Build a testimonials section unlike standard review sliders by creating an elegant masonry-style layout with premium glass cards featuring customer stories, five-star ratings, profile photos, and subtle background illustrations. Create a stylish FAQ section using accordion panels integrated into a curved container with accompanying support illustrations. Finish the homepage with a visually stunning call-to-action section designed as a large floating premium card over a soft abstract gradient background encouraging users to explore available broadband and cable services in their area. Include two highly visible CTA buttons labeled "Check Coverage" and "Talk to an Expert."

Complete the website with a sophisticated multi-column footer featuring Quick Links, Broadband, Cable TV, Coverage, Support, FAQ, Privacy Policy, Terms & Conditions, Refund Policy, Disclaimer, and Contact information. Only within the footer, disclaimer, terms, refund policy, and contact page should it clearly state that the business operates as an independent third-party service provider offering assistance with broadband and cable connection requests and is not affiliated with, endorsed by, or representing any internet service provider, cable operator, or telecommunications company. Do not repeat this information throughout the homepage or include it in the hero section or H1. Ensure the website is fully responsive, mobile-first, SEO-friendly, optimized for Core Web Vitals, Google Ads-friendly, and built with clean modern UI principles. The final result should feel more like a premium technology brand or modern digital service platform than a traditional ISP website, with every section featuring unique layouts, premium visual storytelling, and an unforgettable user experience.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

This is a client-side single-page application built with Vite, React, and TanStack Router.
